## Evidence vocabulary
- **VERIFIED:** directly observed, reproducible evidence.
- **PROPOSED:** design recommendation not implemented.
- **IMPLEMENTED:** code/configuration exists in a named revision.
- **TESTED:** named test ran and its result is recorded.
- **DEPLOYED:** a specific revision is deployed to a named environment.
- **BLOCKED:** required evidence or permission is unavailable.
- **PRODUCTION READY:** all release gates are met with evidence and an explicit decision.

Never report a test, deployment, security review, backup or recovery exercise that has not occurred.

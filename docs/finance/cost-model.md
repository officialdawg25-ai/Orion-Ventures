# Cost model

**Status:** PROPOSED assumptions; no vendor commitments made.

## Categories
Application hosting/compute; database plan, storage, egress, backups and observability; domain and transactional email; document storage and scanning; CI/build minutes and security tooling; AI model usage and retrieval; accounting/CRM/marketing integrations; monitoring, incident response and professional advice.

## Scenarios
Model **bootstrap**, **early traction** and **scaled portfolio**. Specify active users, ventures, monthly records, storage, downloads, email volume, AI requests/tokens, external API calls and retention. Use current regional pricing and measured usage.

## Controls
- Separate fixed recurring costs from variable usage.
- Record currency, billing interval, tax treatment, promotional expiry and renewal price.
- Track free-tier limits and the point where a paid plan is required.
- Estimate cost per active venture/user.
- Set usage alerts and spend caps where available.
- Avoid sending sensitive data to AI providers without a documented purpose, retention assessment and access controls.

## Procurement gate
Record purpose, alternatives, data processed, contract terms, export path, owner, monthly limit, cancellation path and approval. Do not call a service production-free without checking usage limits and commercial terms.
